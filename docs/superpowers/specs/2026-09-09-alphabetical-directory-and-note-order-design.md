# 字母目录与笔记排序设计

## 目标

以大写字母 A–P 为知识库一级目录排序键，并以两位数字为目录内 Markdown 文件排序键，使 Obsidian 文件浏览器呈现稳定、清晰的阅读顺序。

## 命名规则

- 一级目录由现有 `00`–`15` 依次改为 `A`–`P`，例如 `00-用户指南` → `A-用户指南`、`P-就业市场`。
- 每个 Markdown 文件以 `00-` 至 `03-` 前缀排序。
- 各领域 MOC 使用 `00-` 前缀；指南、阶段、实验、ADR、项目、访谈等其他笔记按阅读或使用顺序编号。
- 保留文件名中已有的 AI、LLM、RAG、FDE、MOC、ADR、EXP、RETRO、PRJ 等技术或类型缩写。

## 范围

- 重命名 A–P 对应的知识库目录及其 Markdown 文件。
- 仅更新这些知识库 Markdown 文件中的相对 Markdown 链接目标；不修改链接显示文本、正文或标题。
- 不修改根目录文档、`90-Templates`、`99-Assets`、`.obsidian`、`.gitignore` 或 `docs/superpowers/`。

## 验证

- 重命名前检查目录和文件目标路径没有冲突。
- 完成后确认 A–P 目录和每个笔记的数字前缀正确。
- 对知识库 Markdown 链接进行存在性扫描，确保改名后的内部链接有效。
- 使用 `git diff --check` 审核变更，并排除现有未提交的 `.gitignore` / `.obsidian` 改动。
