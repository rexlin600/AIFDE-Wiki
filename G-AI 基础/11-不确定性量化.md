# 不确定性量化

## 一句话定义

不确定性量化（Uncertainty Quantification）用概率、区间和校准指标表达预测或估计有多可信，以及不确定性来自哪里。

## 本篇范围

本篇区分数据与模型不确定性、置信区间与预测区间、概率置信度与校准，并介绍覆盖率、Brier Score、Bootstrap 和分布外输入。具体贝叶斯计算和共形预测留作进阶主题。

## 前置知识

需要理解[概率统计](02-概率统计.md)中的分布、方差、抽样和置信区间，以及[最大似然与最大后验](08-最大似然与最大后验.md)中的点估计和后验概念。

## 为什么重要

“模型预测为阳性”只给结论；“预测概率 0.8”给出一个分数；“在同类样本中约 80% 确实为阳性，且当前输入没有明显偏离训练分布”才开始形成可行动的可信度说明。

## 两类主要不确定性

### 数据不确定性

也称偶然不确定性（Aleatoric Uncertainty），来自观测噪声或过程本身的随机性。例如相同条件下交付时间仍会波动。获得更多同类数据可以更准确地估计这种噪声，但无法完全消除过程本身的随机性。

### 模型不确定性

也称认知不确定性（Epistemic Uncertainty），来自数据不足、模型结构不合适或参数尚不确定。补充覆盖相关区域的高质量数据可能降低它。

这一区分依赖建模方式，同一种误差在不同模型中可能被归到不同来源。

## 点估计和区间

### 置信区间

置信区间针对未知参数或平均响应。例如总体平均延迟的区间，表达我们对平均值估计的抽样不确定性。

### 预测区间

预测区间针对一个未来观测。它同时包含参数估计不确定性和新观测自身噪声，因此在相同置信水平下通常比平均值置信区间更宽。

以简单正态模型且均值、方差由样本估计为例，平均值区间的尺度约为 $s/\sqrt n$；单个新观测的预测区间还包含 $s$ 本身的波动，尺度约为

$$
s\sqrt{1+\frac1n}
$$

不能用平均响应的窄区间冒充单个用户结果的预测区间。

## 分类概率与校准

若模型把一组样本都预测为 0.8，而这组样本长期约有 80% 为正类，模型在这个概率水平上是校准的。

可靠性图把预测概率分箱，比较每箱平均置信度与真实正例率。完美校准点位于对角线附近。

### Brier Score

二分类的 Brier Score 为

$$
\operatorname{BS}=\frac1n\sum_{i=1}^{n}(p_i-y_i)^2
$$

$p_i\in[0,1]$ 是正类预测概率，$y_i\in\{0,1\}$ 是真实标签。分数越低越好，它同时受校准和区分能力影响，不能只把它解释成校准误差。

### 手算示例

预测为 $[0.9,0.7,0.2]$，标签为 $[1,0,0]$：

$$
\operatorname{BS}=\frac{(0.9-1)^2+(0.7-0)^2+(0.2-0)^2}{3}=0.18
$$

第二个样本自信但错误，贡献 $0.49$，远大于另外两个样本。

## Bootstrap

Bootstrap 从已有 $n$ 个样本中“有放回”抽取 $n$ 个样本，重复计算统计量。许多次重采样结果的分布近似统计量的抽样分布，可用于标准误和区间估计。

步骤是：

1. 从原样本有放回抽取一个同样大小的新样本；
2. 计算关心的指标；
3. 重复许多次；
4. 使用经验分位数或其他校正方法形成区间。

Bootstrap 继承原样本偏差。时间序列、用户簇或长尾稀有事件不能不考虑依赖结构就逐行重采样。

## 分布外不确定性

分布外（Out-of-Distribution，OOD）输入来自训练分布覆盖不足的区域。
普通 Softmax 仍可能对 OOD 输入给出很高概率，因此最大概率不是通用的
OOD 保证。

工程上应结合输入质量规则、距离或密度信号、独立 OOD 测试集、拒答策略和人工升级。没有单一分数能覆盖所有未知变化。

## NumPy 实验

```python
import numpy as np

rng = np.random.default_rng(11)
sample = rng.normal(loc=10.0, scale=2.0, size=200)
bootstrap_means = np.array([
    rng.choice(sample, size=sample.size, replace=True).mean()
    for _ in range(4000)
])
lower, upper = np.quantile(bootstrap_means, [0.025, 0.975])

probabilities = np.array([0.9, 0.7, 0.2])
labels = np.array([1.0, 0.0, 0.0])
brier = np.mean((probabilities - labels) ** 2)

assert lower < sample.mean() < upper
assert np.isclose(brier, 0.18)
print(round(lower, 3), round(upper, 3))
print(brier)
```

Bootstrap 区间描述样本均值的抽样变化；Brier Score 则评价概率预测，两者回答不同问题。

## AI 工程实践

- 在与使用场景一致的独立数据上检查覆盖率和校准，不能只在训练集评估。
- 校准会随时间、地区、用户群体和基准率漂移，需要分群监控和定期复核。
- 区间必须说明对象、方法、置信水平和假设，例如“均值的 95% Bootstrap 区间”。
- 不确定性应连接行动：自动执行、请求更多信息、拒答、人工复核或降级。
- 风险高的场景不能把单个模型概率当作安全保证。

## 公式看不懂时

区间不是在结果附近随意加减一个数，而是在假设和重复过程下校准出来的范围。校准则问：模型说“八成把握”的事情，长期是否真的约八成发生。

## 适用与不适用场景

不确定性量化适合风险分级、人工升级、样本选择和预测沟通。若评测数据不代表部署环境、标签本身有偏或数据持续漂移，再精细的区间也可能给出错误安全感。

## 常见误区

- **概率高就一定校准。** 高置信只是单次输出，校准是群体上的频率性质。
- **置信区间就是预测区间。** 前者通常针对参数或平均响应，后者针对新观测。
- **区间越窄越好。** 过窄但覆盖不足的区间是不可信的。
- **Bootstrap 能修复有偏样本。** 它主要重现已有样本的经验分布，也会重现其偏差。

## 如何给别人讲清楚

1. 区分“世界本身会变”和“我们还不了解世界”。
2. 用平均交付时间和下一单交付时间区分两类区间。
3. 用天气预报解释概率校准。
4. 手算三个样本的 Brier Score。
5. 用 OOD 输入说明高概率为何不等于安全。
