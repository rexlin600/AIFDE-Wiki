# 数学与 AI 基础 MOC

## 领域边界

本领域建立理解数据、模型、损失、优化和不确定性所需的最低数学语言。目标是能解释公式、检查实现并设计实验，不追求完整的数学专业训练，也不展开具体机器学习算法。

## 前置知识

- 高中代数、函数、指数与对数。
- Python 基础，能使用 NumPy 操作数组并绘制简单图表。
- 能区分变量、参数、样本和指标。

## 推荐顺序

1. 先学习线性代数，建立向量、矩阵、张量和相似度直觉。
2. 再学习概率统计与信息论，理解数据、预测和损失中的不确定性。
3. 接着学习微积分、梯度和链式法则，理解参数如何更新。
4. 最后结合优化与数值稳定性完成可验证的计算实验。

## 最小实验

- 用 NumPy 实现向量相似度和矩阵乘法，以形状断言验证批处理结果。
- 对一元函数比较解析梯度、有限差分和自动微分，记录误差随步长的变化。
- 对同一组 logits 分别使用直接计算与稳定写法计算 softmax 和交叉熵，构造极端输入观察溢出。

## 项目

- 在 `ai-foundations-labs` 中维护数学机制实验，每个实验固定输入、随机种子和误差容限。
- 将线性代数、概率和梯度实验作为[阶段 1：AI/ML 基础](../F-%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF/02-%E9%98%B6%E6%AE%B5%201-AI%20%E4%B8%8E%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0%E5%9F%BA%E7%A1%80.md)的可复现证据。

## 开源研究

- 跟踪 NumPy 的广播和矩阵乘法行为，记录 API 约定、形状规则与错误路径。
- 跟踪 PyTorch Autograd 从标量损失到叶子张量梯度的一条最小调用链。
- 最小复刻数值梯度检查，并与框架自动微分结果对照。

## 面试入口

- 解释向量相似度、矩阵乘法和张量形状如何出现在 Embedding 与 Attention 中。
- 推导一个两层计算图的链式法则，并说明梯度消失或爆炸的数值原因。
- 解释交叉熵与最大似然的关系，以及为什么概率输出仍需校准。
