# 机器学习 MOC

## 领域边界

本领域关注如何从数据、特征、目标和验证方案构建可泛化的预测系统，并建立判断“是否需要深度学习或 LLM”的可靠基线。范围包含经典监督与无监督学习、数据与评测方法，不展开神经网络内部机制。

## 前置知识

- [数学与 AI 基础](../02-AI%20%E5%9F%BA%E7%A1%80/AI%20%E5%9F%BA%E7%A1%80-MOC.md)中的向量、概率、梯度、损失和优化。
- Python、NumPy 与表格数据处理基础。
- 能把业务问题表述为目标变量、输入特征、约束和错误成本。

## 推荐顺序

1. 先用回归和分类理解训练、泛化、正则化与指标。
2. 再学习树与 Boosting，并用 Pipeline 建立强表格基线。
3. 接着学习聚类、降维和异常检测，理解无标签任务的验证限制。
4. 最后进入推荐、时间序列，以及横切所有任务的特征工程、泄漏与校准。

## 最小实验

- 在同一公开表格数据集上比较多数类规则、逻辑回归和梯度提升，固定拆分与随机种子。
- 人为加入一个泄漏特征，观察验证分数异常升高，再通过特征生成时点审计定位它。
- 对分类模型绘制 Precision-Recall 与校准曲线，依据两种错误成本选择阈值。

## 开源研究

- 跟踪 scikit-learn Estimator 的 `fit`、`predict` 与 Pipeline 参数传递路径。
- 比较一个树模型库的训练参数、缺失值策略和模型序列化约定。
- 用 NumPy 最小复刻逻辑回归，并与成熟实现比较梯度和预测概率。

## 面试入口

- 为类别不平衡业务选择验证方案、指标和阈值，并说明错误成本。
- 排查离线分数异常高、线上效果下降的问题，优先验证泄漏与分布漂移。
- 比较线性模型、树模型和神经网络在数据量、解释性与维护成本上的取舍。
