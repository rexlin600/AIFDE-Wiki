# 检索增强生成 RAG MOC

<!-- markdownlint-disable MD012 MD013 -->

## 为什么学习 RAG

RAG 不是“向量数据库加大模型”，而是一条把外部知识变成可授权、可检索、可引用回答的证据链。理解本目录后，你应能定位答案错误发生在数据、召回、排序、上下文还是生成，选择最简单有效的改进，并量化质量、延迟、成本、时效与安全。

## 领域边界

本目录讲数据进入、索引、查询理解、候选检索、上下文、引用与 RAG 评测。[大模型 LLM](../J-%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM/00-%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM-MOC.md)负责生成、Embedding 和上下文窗口原理；[智能体 Agent](../L-%E6%99%BA%E8%83%BD%E4%BD%93%20Agent/00-%E6%99%BA%E8%83%BD%E4%BD%93%20Agent-MOC.md)负责通用工具规划；[多模态 AI](../M-%E5%A4%9A%E6%A8%A1%E6%80%81%20AI/00-%E5%A4%9A%E6%A8%A1%E6%80%81%20AI-MOC.md)负责视觉与音频模型；[生产级 AI](../N-%E7%94%9F%E4%BA%A7%E7%BA%A7%20AI/00-%E7%94%9F%E4%BA%A7%E7%BA%A7%20AI-MOC.md)负责通用平台运行。

## 按 RAG 生命周期学习

### 数据进入知识库

1. [RAG 数据摄取](<03-RAG 数据摄取.md>)：来源、版本、幂等和可重建性。
2. [RAG 文档解析](<04-RAG 文档解析.md>)：把文件和版面变成统一文档结构。
3. [RAG 文档清洗](<05-RAG 文档清洗.md>)：去噪、去重且不误删正文。
4. [RAG 文档切分](<06-RAG 文档切分.md>)：决定检索粒度、重叠和边界。
5. [RAG 元数据](<07-RAG 元数据.md>)：记录来源、权限、时间和过滤字段。

### 建立召回和排序

1. [BM25 稀疏检索](<08-BM25 稀疏检索.md>)：处理关键词、编号和罕见词项。
2. [Dense 向量检索](<09-Dense 向量检索.md>)：处理语义近似和表达变化。
3. [RAG 向量索引](<10-RAG 向量索引.md>)：权衡精确搜索、ANN、速度和召回。
4. [混合检索 Hybrid Search](<02-混合检索 Hybrid Search.md>)：融合 Sparse 与 Dense 排名。
5. [RAG 重排序](<11-RAG 重排序.md>)：对有限候选做更精细相关性判断。
6. [父子文档检索](<12-父子文档检索.md>)：分离检索粒度与生成粒度。

### 理解和变换查询

1. [RAG 查询改写](<13-RAG 查询改写.md>)：消歧和规范化，同时保持原意。
2. [RAG 多查询检索](<14-RAG 多查询检索.md>)：从多个表达扩大召回。
3. [RAG 查询分解](<15-RAG 查询分解.md>)：拆解复合问题和依赖关系。
4. [RAG 检索路由](<16-RAG 检索路由.md>)：选择数据源与检索器。
5. [HyDE 假设文档检索](<17-HyDE 假设文档检索.md>)：用假设答案靠近文档表达。
6. [多轮对话检索](<18-多轮对话检索.md>)：处理指代、历史和会话边界。
7. [RAG 多跳检索](<19-RAG 多跳检索.md>)：连接跨文档证据链。

### 按结果调整检索

1. [RAG 自适应检索](<20-RAG 自适应检索.md>)：决定是否检索和检索深度。
2. [RAG 迭代检索](<21-RAG 迭代检索.md>)：根据中间证据继续检索。
3. [RAG 纠错检索](<22-RAG 纠错检索.md>)：低质量证据时补检、换源或降级。
4. [Self-RAG 自反思检索](<23-Self-RAG 自反思检索.md>)：显式判断检索必要性和支持度。
5. [Agentic RAG](<24-Agentic RAG.md>)：用受控工具状态机规划检索。

### 使用图和层级结构

1. [GraphRAG](25-GraphRAG.md)：从实体关系和社区摘要回答局部或全局问题。

### 构建可用证据

## 按故障现象学习

| 现象 | 优先入口 | 首要检查 |
| --- | --- | --- |
| 编号或专有名词搜不到 | BM25 与混合检索 | 分词、字段、Sparse 候选 |
| 同义问题搜不到 | Dense 与查询改写 | Embedding、困难负例、意图漂移 |
| 文档已召回却排太后 | RAG 重排序 | 候选窗口、相关性标签 |
| 片段相关但缺上下文 | 父子文档与上下文构建 | 父子映射、Token 预算 |
| 复合问题漏一部分 | 查询分解与多跳检索 | 子问题覆盖、证据链、终止 |
| 回答正确但引用错误 | RAG 引用生成 | 主张归属、原文位置、权限 |
| 答案忠实但事实过期 | RAG 知识时效 | 有效期、来源权威、索引水位 |
| 撤权后仍能搜到 | 权限控制与流式更新 | ACL 版本、墓碑、缓存 |
| 复杂流程无限循环 | 迭代或 Agentic RAG | 最大步数、预算、终止原因 |
| 延迟和成本失控 | 检索评测与方案选型 | 候选数、循环数、上下文 Token |

## 按问题选择方法

| 问题特征 | 优先方法 | 不要先做什么 |
| --- | --- | --- |
| 精确词项和编号为主 | BM25 | 只用 Dense |
| 自然语言释义为主 | Dense | 只靠关键词堆叠 |
| 两类查询混合 | Hybrid | 直接相加异构原始分数 |
| 候选已包含证据但顺序差 | Rerank | 增加更多生成 Token |
| 材料小且单次明确 | 长上下文基线 | 建复杂索引平台 |
| 动态且需要引用的知识 | RAG | 用微调记忆变化事实 |
| 实时数值或动作 | 结构化查询与工具 | 从旧文档猜测 |
| 跨实体关系和全局主题 | 先多跳再评估 GraphRAG | 未做基线就建图 |

## 统一术语

- Document 是原始或逻辑文档，Chunk 是可索引片段，Evidence 是被用于回答的可核验证据。
- Candidate Generation 负责找回候选，Rerank 只能重排已有候选。
- qrels 是查询与文档相关性标注；答案参考与检索 qrels 不是同一件事。
- Faithfulness 判断答案是否由给定证据支持，不自动判断来源本身是否真实。
- 模型生成的查询、路由、引用和动作都是提议，授权与执行由确定性程序负责。

## 上线检查表

| 阶段 | 必须能回答的问题 |
| --- | --- |
| 数据 | 来源、许可、版本、删除和重建方式是什么 |
| 索引 | Tokenizer、Embedding、字段和索引版本是什么 |
| 权限 | 过滤在哪个边界生效，缓存怎样隔离 |
| 检索 | 各查询切片的 Recall、MRR、nDCG 和延迟是多少 |
| 上下文 | 怎样去重、排序、压缩并保留来源映射 |
| 生成 | 怎样验证主张、引用和不可回答拒答 |
| 更新 | 源到索引水位、幂等、墓碑和对账怎样工作 |
| 决策 | 每个复杂组件相对简单基线带来多少净收益 |
