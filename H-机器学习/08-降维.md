# 降维

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

降维用较少的新变量概括高维数据，可用于压缩、去噪、可视化或加速下游模型。它必须说明保留了什么信息、丢失了什么信息，而不是把二维图当结论。

## 不理解会造成什么错误

- 未缩放就做 PCA，让方差最大的单位支配方向。
- 在全量数据上拟合 PCA 后再交叉验证。
- 把二维图中的距离当作原空间真实距离。
- 只看解释方差，不检查下游预测或业务信息。

## 它在建模工作流中的位置

PCA 属于要在训练折内拟合的[特征工程](04-特征工程.md)。若只用于探索，要清楚图形可能扭曲；若用于生产，要与不降维基线比较效果、延迟和稳定性。

## 从高维用户特征开始

样本是一名用户，输入为 100 个相关消费特征，输出为 10 个主成分。目标可能是加速流失模型，也可能只是探索。预测时点决定原始统计窗口；未来数据不能参与 PCA 方向的学习。

## 核心机制

PCA 寻找单位方向 $v$，使中心化数据投影 $Xv$ 的方差最大：

$$
v_1=\arg\max_{\lVert v\rVert=1}\operatorname{Var}(Xv)
$$

后续方向与已有方向正交。解释方差比表示每个主成分承载的总方差比例。主成分是原特征的线性组合，正负号可以整体翻转而不改变含义。

## 最小手算

点 `(1,1)`、`(2,2)`、`(3,3)` 全在直线 $x_1=x_2$ 上。沿 $(1,1)/\sqrt2$ 投影保留全部变化，垂直方向方差为 0，因此二维数据可无损压成一维。

## 可执行实验

```python
from sklearn.datasets import make_classification
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_classification(
    n_samples=800, n_features=40, n_informative=8,
    n_redundant=20, random_state=42
)
baseline = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
reduced = make_pipeline(
    StandardScaler(), PCA(n_components=0.9, svd_solver="full"),
    LogisticRegression(max_iter=1000)
)
for name, model in (("all", baseline), ("pca", reduced)):
    scores = cross_val_score(model, X, y, cv=5, scoring="roc_auc")
    print(name, round(scores.mean(), 3), round(scores.std(), 3))
reduced.fit(X, y)
print("components", reduced[1].n_components_)
```

PCA 用更少维度保留 90% 方差，但下游 AUC 可能升、降或不变；标签相关方向未必是方差最大方向。

## 评测与结果解释

压缩任务看维度、重构误差、存储和延迟；预测任务看独立验证的下游指标；可视化只作为探索。跨时间比较主成分时，要检查子空间和载荷稳定性。

## 数据与泄漏风险

中心化、缩放和 PCA 都只能在训练数据拟合，并放进 Pipeline。若用户重复出现，还需先解决实体拆分。敏感信息可能仍编码在主成分中，降维不等于匿名化。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 第一成分几乎等于金额 | 未缩放或真实方差主导 | 单位、StandardScaler、载荷 |
| 方差保留高但 AUC 下降 | 标签信号位于低方差方向 | 下游 CV、监督特征选择 |
| 二维图簇很漂亮 | 投影扭曲或调参偏见 | 原空间邻域、独立验证 |
| 重训成分含义变化 | 数据漂移或近似重根 | 载荷、子空间相似度、版本 |

## 适用与不适用场景

PCA 适合线性相关、需要压缩或去噪的数据。不适合直接表达强非线性流形，也不保证可解释或保留标签信号。树模型对少量表格特征通常不需要 PCA。

## 学习收益

你应能解释 PCA 优化目标和解释方差，判断缩放与泄漏风险，并用下游指标验证降维是否真正有益。

## 给别人讲清楚

“PCA 像换一个观察角度，把变化最多的方向放在前面；它保留的是总体变化，不保证保留任务最需要的信息。”
