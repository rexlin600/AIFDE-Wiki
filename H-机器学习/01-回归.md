# 回归

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

回归预测连续数值，例如订单还需多少分钟送达、下周销量或房屋价格。它不仅给出一个数，还帮助我们量化误差、发现系统偏差，并支持排班、库存或报价决策。

## 不理解会造成什么错误

- 把“平均误差很小”误解成每笔订单都准确。
- 用百分比误差评价可能为零的目标。
- 在训练集看分数，忽略对新订单的泛化能力。
- 让未来才出现的实际完成信息进入特征。

## 它在建模工作流中的位置

上游定义样本、目标和预测时点；下游用[指标](06-指标.md)比较基线、检查残差，并通过[验证设计](11-验证设计.md)确认改善能延续到未来。

## 从订单交付案例开始

| 要素 | 定义 |
| --- | --- |
| 样本 | 用户刚完成支付的一笔订单 |
| 特征 | 距离、商品数、下单小时、当时待配送单量 |
| 目标 | 从支付到签收的分钟数 |
| 预测时点 | 支付成功的一刻 |
| 错误成本 | 低估导致投诉，高估降低下单意愿 |

先用训练集目标均值预测所有订单。新模型若不能稳定超过均值基线，就没有证明自己学到了可部署的信息。

## 核心机制

线性回归把预测写成特征的加权和：

$$
\hat y=w_0+w_1x_1+\cdots+w_dx_d
$$

权重表示其他特征不变时，输入增加一个单位带来的预测变化。训练常最小化均方误差：

$$
\operatorname{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2
$$

平方让大误差受到更重惩罚。Ridge 再加入 $\lambda\sum_jw_j^2$ 限制权重过大，在特征相关或样本较少时更稳定。矩阵表达和求解原理见 [线性代数](../G-AI%20%E5%9F%BA%E7%A1%80/01-%E7%BA%BF%E6%80%A7%E4%BB%A3%E6%95%B0.md)与[优化](../G-AI%20%E5%9F%BA%E7%A1%80/04-%E4%BC%98%E5%8C%96.md)。

## 最小手算

真实时长为 20、30、70 分钟，均值基线预测 40：

$$
\operatorname{MAE}=(20+10+30)/3=20
$$

$$
\operatorname{RMSE}=\sqrt{(400+100+900)/3}\approx21.60
$$

RMSE 更大，因为 30 分钟的大误差被平方后影响更强。选择哪个指标取决于“大错”是否具有额外成本。

## 可执行实验

```python
import numpy as np
from sklearn.datasets import make_regression
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.metrics import mean_absolute_error, root_mean_squared_error
from sklearn.model_selection import train_test_split

X, y = make_regression(n_samples=400, n_features=8, noise=30, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
predictions = {
    "mean": np.full_like(y_test, y_train.mean()),
    "linear": LinearRegression().fit(X_train, y_train).predict(X_test),
    "ridge": Ridge(alpha=10).fit(X_train, y_train).predict(X_test),
}
for name, prediction in predictions.items():
    mae = mean_absolute_error(y_test, prediction)
    rmse = root_mean_squared_error(y_test, prediction)
    print(name, "MAE", round(mae, 2), "RMSE", round(rmse, 2))
```

线性模型应显著超过均值基线；Ridge 未必胜出，因为正则化是偏差与方差的交换，不是免费提升。

## 评测与结果解释

- **MAE：** 平均偏离多少目标单位，最容易解释。
- **RMSE：** 更在意少数大误差。
- **$R^2$：** 相比预测均值解释了多少方差，测试集上可以为负。
- **残差：** $e=y-\hat y$。按距离、门店和时段分组可发现系统偏差。

调参只看验证集，测试集留到最后。若目标随时间漂移，应按时间回测而不是随机拆分。

## 数据与泄漏风险

签收后才产生的实际路线、最终退款状态和完成时间都不可用。门店平均时长也必须只用预测时点以前的数据计算。目标做对数变换时，指标仍应回到分钟尺度解释。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 训练好测试差 | 过拟合或拆分错位 | 学习曲线、时间拆分、重复订单 |
| 大订单误差极高 | 关系非线性或长尾 | 残差分组、目标分布、树模型 |
| 预测出现负时长 | 线性输出无边界 | 目标变换、截断规则、GLM |
| 线上整体偏低 | 数据漂移或特征延迟 | 近期残差、输入分布、时间戳 |

## 适用与不适用场景

线性或 Ridge 适合作为可解释、训练快的基线。明显非线性且交互复杂的表格数据可比较[树与 Boosting](<03-树与 Boosting.md>)。目标是类别、排序或生存时间时不应硬套普通回归。

## 学习收益

你应能定义回归问题，手算 MAE 与 RMSE，建立均值基线，解释线性权重与正则化，并用残差定位业务切片中的失败。

## 给别人讲清楚

“回归是在预测一个数。先问永远猜平均值能有多准，再让模型用当时可见的特征修正平均值，最后检查重要人群和时段的误差。”
