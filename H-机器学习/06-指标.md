# 指标

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

指标把模型错误压缩成可比较的数字。真正的问题不是“哪个指标最好”，而是它是否对应部署目标、错误成本、样本分布和行动容量。

## 不理解会造成什么错误

- 类别不平衡时只看 Accuracy。
- 用 AUC 选出的模型直接按 0.5 上线。
- 只报总体平均，掩盖重要人群的严重失败。
- 在测试集挑指标、阈值和模型，形成评测过拟合。

## 它在建模工作流中的位置

业务目标确定后就要定义主指标、守护指标和成本；训练时用验证集选择方案，最后才用测试集做一次独立估计。指标连接[分类](02-分类.md)、[回归](01-回归.md)和[校准](10-校准.md)。

## 从挽留决策开始

每触达一名客户成本 10 元，成功挽留价值 100 元。模型输出流失概率，运营每天最多联系 1000 人。因此除 AUC，还要关注前 1000 名的 Precision、预计净收益和人群公平性。

## 分类指标

$$
\text{Precision}=\frac{TP}{TP+FP},\qquad
\text{Recall}=\frac{TP}{TP+FN}
$$

$$
F_1=2\frac{\text{Precision}\cdot\text{Recall}}
{\text{Precision}+\text{Recall}}
$$

ROC-AUC 衡量全阈值排序；正类稀少时 PR 曲线更直观。Log Loss 和 Brier Score 使用概率信息。混淆矩阵必须先声明哪一类是正类。

## 回归与排序指标

- MAE 与目标同单位，代表典型绝对误差。
- RMSE 更重罚大错。
- MAPE 在真实值为零或很小时失真。
- Recall@K、NDCG@K 用于每个用户的前 K 个推荐，不能用普通 Accuracy 替代。

## 最小手算

100 人中 10 人会流失。模型选出 8 人，其中 6 人真流失：TP=6、FP=2、FN=4、TN=88。因此 Accuracy=94%，Precision=75%，Recall=60%。高 Accuracy 并未表达只找回六成流失客户。

## 可执行实验

```python
import numpy as np
from sklearn.metrics import confusion_matrix, precision_score, recall_score

y_true = np.array([1, 1, 1, 0, 0, 0, 0, 0])
probability = np.array([0.9, 0.6, 0.3, 0.8, 0.4, 0.2, 0.1, 0.05])
for threshold in (0.25, 0.5, 0.75):
    prediction = probability >= threshold
    tn, fp, fn, tp = confusion_matrix(y_true, prediction).ravel()
    cost = 10 * (tp + fp) + 100 * fn
    print(threshold, "P", round(precision_score(y_true, prediction), 2),
          "R", round(recall_score(y_true, prediction), 2), "cost", cost)
```

这里假设每次触达成本 10、每个漏报损失 100。成本函数改变时，最优阈值也会改变。

## 评测与结果解释

先明确统计单位：按订单、用户还是金额加权。报告点估计之外还应给多折方差或置信区间。模型比较使用相同样本，并检查关键切片。线上实验最终要验证业务结果，而不仅是离线代理指标。

## 数据与泄漏风险

评测标签必须在完整观察窗口后成熟；未成熟样本会被误记为负类。测试集不能参与指标、阈值和切片的筛选。频繁尝试后只报告最好结果，也是一种对测试集的过拟合。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| Accuracy 高但业务差 | 类别不平衡 | 基准率、混淆矩阵、成本 |
| 离线收益高线上亏损 | 成本假设或容量错误 | 真实单价、触达上限、因果增量 |
| 指标突然下降 | 标签延迟或分布变化 | 标签成熟度、分时段基准率 |
| 总体好但投诉集中 | 切片被平均掩盖 | 地区、设备、群体指标 |

## 适用与不适用场景

指标必须成组使用：主指标优化目标，守护指标限制副作用，业务指标验证最终价值。不要用一个数字同时声称排序、概率和决策都好。

## 学习收益

你应能手算分类指标，区分排序、概率与决策质量，把错误成本写成阈值规则，并设计总体与切片报告。

## 给别人讲清楚

“指标是尺子。先决定什么错误最贵、每天能处理多少，再选择尺子；不能因为一把尺子数字漂亮，就说产品一定有效。”
