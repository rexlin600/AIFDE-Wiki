# 机器学习 MOC

## 为什么学习机器学习

机器学习不是“挑一个算法跑分”，而是把历史数据变成对未来未知样本仍有效的预测或决策系统。学完本目录，你应能把业务目标翻译成样本、标签和错误成本，建立可信基线，设计不泄漏的验证，并判断模型是否值得上线。

## 领域边界

本目录讲建模、验证、交付与排错。公式需要用到时会逐层解释，但完整数学原理链接到 [AI 基础](../G-AI%20%E5%9F%BA%E7%A1%80/00-AI%20%E5%9F%BA%E7%A1%80-MOC.md)。神经网络内部机制属于[深度学习](../I-%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0/00-%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0-MOC.md)。

## 建模工作流

1. **明确决策：** [指标](06-指标.md)把误报、漏报和数值误差换成业务成本。
2. **定义数据：** 明确样本、标签、预测时点，用[数据泄漏](05-数据泄漏.md)审计当时可用的信息。
3. **设计验证：** [验证设计](11-验证设计.md)让离线测试模拟真实部署。
4. **准备输入：** [特征工程](04-特征工程.md)用 Pipeline 保持训练与服务一致。
5. **建立基线：** 连续值看[回归](01-回归.md)，类别看[分类](02-分类.md)，表格数据再比较[树与 Boosting](<03-树与 Boosting.md>)。
6. **分析输出：** 根据成本选阈值，用[校准](10-校准.md)判断概率能否直接解释。
7. **上线运行：** 参考[在线学习](14-在线学习.md)监控漂移，准备重训、降级与人工兜底。

| 任务 | 你要回答的问题 | 主题 |
| --- | --- | --- |

| 数据与评测 | 分数是否可信，模型能否上线 | [特征工程](04-特征工程.md)、[数据泄漏](05-数据泄漏.md)、[指标](06-指标.md)、[校准](10-校准.md)、[验证设计](11-验证设计.md) |

## 推荐学习路线

- **第一次入门：** 回归 → 分类 → 指标 → 验证设计 → 特征工程 → 数据泄漏。
- **表格建模：** 分类或回归 → 树与 Boosting → 指标 → 校准 → 验证设计。
- **无标签数据：** 聚类 → 降维 → 异常检测，同时补验证设计。
- **专项问题：** 推荐、时序、在线和因果可独立进入，但先掌握指标与泄漏。

## 上线检查表

| 阶段 | 必须能回答的问题 |
| --- | --- |
| 问题定义 | 为谁、何时、预测什么、预测后采取什么动作 |
| 数据 | 每行代表什么，标签何时产生，线上能否取得相同特征 |
| 验证 | 拆分是否复刻时间、用户、设备或门店边界 |
| 基线 | 不使用复杂模型时能做到多好 |
| 评测 | 指标和阈值是否对应真实错误成本 |
| 上线 | 如何监控，何时重训，失败时如何降级 |

## 实践项目

选择一个表格预测问题，保存数据说明、时间边界、Pipeline、基线、候选模型、阈值报告与错误案例。再故意加入未来信息特征，观察分数异常升高，并用[数据泄漏](05-数据泄漏.md)中的清单定位它。
