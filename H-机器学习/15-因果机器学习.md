# 因果机器学习

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

普通机器学习问“谁会购买”，因果机器学习问“给谁发券会让购买概率增加”。后者关心干预的增量效果，需要反事实和识别假设，预测准确不能自动回答。

## 不理解会造成什么错误

- 把高购买概率客户当成最容易被优惠券影响的人。
- 比较领券人与未领券人的均值，忽略投放选择偏差。
- 倾向得分接近 0 或 1 时仍强行外推。
- 只验证结果预测精度，不验证策略价值和识别假设。

## 它在建模工作流中的位置

先明确处理 $T$、结果 $Y$、干预前协变量 $X$ 和目标人群，再优先做随机实验。无法随机化时才依赖观察数据的可交换性、共同支持和一致性假设。

## 从优惠券案例开始

样本是活动前符合资格的用户，处理是是否发券，结果是 7 天内购买，特征只能来自发券前。目标不是预测购买，而是估计个体条件效应：

$$
\tau(x)=E[Y(1)-Y(0)\mid X=x]
$$

$Y(1)$ 是发券时的潜在结果，$Y(0)$ 是不发券时的潜在结果；同一个人只能观察其中一个，这就是因果推断的根本困难。

## 先建立简单基线

随机实验中，总体平均处理效应可直接用两组均值差：

$$
\widehat{ATE}=\bar Y_{T=1}-\bar Y_{T=0}
$$

策略基线是不给任何人、给所有人或随机给预算内人群。异质性模型必须证明按其排序发券比这些基线带来更高净增量。

## 观察数据的识别

倾向得分 $e(x)=P(T=1\mid X=x)$ 描述具有这些特征的人接受处理的概率。逆概率加权估计为：

$$
\widehat{ATE}_{IPW}=\frac{1}{n}\sum_i
\left(\frac{T_iY_i}{e(X_i)}-\frac{(1-T_i)Y_i}{1-e(X_i)}\right)
$$

它用权重构造近似平衡的人群。若倾向接近 0 或 1，权重爆炸，说明缺乏共同支持。T-Learner 分别拟合处理组和对照组结果模型，再计算 $\hat\mu_1(x)-\hat\mu_0(x)$。

## 最小手算

随机实验中 100 人发券有 30 人购买，100 人不发券有 20 人购买，ATE 为 $0.30-0.20=0.10$，即平均提升 10 个百分点。不能说每个人都提升 10 个百分点，也不能仅凭这个平均值知道应给谁发券。

## 可执行实验

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestRegressor

rng = np.random.default_rng(42)
n = 3000
X = rng.normal(size=(n, 2))
propensity = 1 / (1 + np.exp(-0.8 * X[:, 0]))
T = rng.binomial(1, propensity)
true_effect = 1 + 0.8 * (X[:, 1] > 0)
Y = 2 + X[:, 0] + T * true_effect + rng.normal(0, 1, n)

e = LogisticRegression(max_iter=1000).fit(X, T).predict_proba(X)[:, 1]
e = np.clip(e, 0.05, 0.95)
ipw = np.mean(T * Y / e - (1 - T) * Y / (1 - e))
m0 = RandomForestRegressor(n_estimators=100, min_samples_leaf=20,
                           random_state=42).fit(X[T == 0], Y[T == 0])
m1 = RandomForestRegressor(n_estimators=100, min_samples_leaf=20,
                           random_state=42).fit(X[T == 1], Y[T == 1])
tau_hat = m1.predict(X) - m0.predict(X)
print("true ATE", round(true_effect.mean(), 3), "IPW", round(ipw, 3))
print("T-learner correlation", round(np.corrcoef(true_effect, tau_hat)[0, 1], 3))
```

合成数据知道真实反事实，因此可检查估计。真实观察数据永远无法仅靠测试分数证明“没有未观测混杂”。

## 评测与结果解释

随机实验用策略价值、增量收益和置信区间评测。观察数据先检查处理组与对照组协变量平衡、倾向分布和有效样本量，再做敏感性分析。个体效应难以直接得到标签，普通 RMSE 不适用。

## 数据与泄漏风险

只能用处理前协变量；优惠券领取、处理后的浏览和中间结果都是处理后变量，控制它们会引入偏差。实验不依从、干扰效应和样本筛选也会破坏简单解释。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 观察效应异常巨大 | 选择偏差或处理后变量 | 投放规则、变量时间、DAG |
| IPW 方差很大 | 倾向接近 0 或 1 | 重叠图、极端权重、目标人群 |
| uplift 离线不稳定 | 样本不足或异质性弱 | 置信区间、多折策略价值 |
| 上线策略无增量 | 预测相关性不等于因果 | 随机对照、成本、干扰效应 |

## 适用与不适用场景

适合营销、医疗、政策和产品干预的增量决策。若只需预测自然发生结果，普通监督学习更简单。关键假设不可信或缺乏共同支持时，应缩小结论范围或设计实验，而不是依靠更复杂模型。

## 学习收益

你应能区分预测与因果，定义潜在结果，手算随机实验 ATE，解释倾向得分、IPW、T-Learner 和共同支持，并知道何时无法识别。

## 给别人讲清楚

“会购买的人不一定是被优惠券说服的人。因果机器学习寻找行动造成的差值，而这个差值需要实验或明确假设才能估计。”
