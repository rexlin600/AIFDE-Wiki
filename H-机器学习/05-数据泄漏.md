# 数据泄漏

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

数据泄漏不是一种模型，而是验证可信度的底线：模型训练时使用了真实预测时不可获得的信息，离线分数就会虚高，线上必然回落。

## 不理解会造成什么错误

- 用取消后的退款状态预测客户取消。
- 同一用户同时进入训练和测试，模型记住身份。
- 全量数据先做填补、缩放、PCA 或特征选择，再交叉验证。
- 用测试集反复选模型、参数或阈值。

## 它在建模工作流中的位置

泄漏审计从问题定义开始，贯穿抽取、拆分、特征、训练和评测。它应在追求更高分之前完成，并与[验证设计](11-验证设计.md)和[特征工程](04-特征工程.md)共同检查。

## 从异常高分开始

流失模型 AUC 达到 0.99，不应先庆祝。逐列检查后发现“关停工单完成时间”只有取消后才产生。删除后 AUC 降到 0.78，后者反而更可信。预测对象是观察日客户，预测时点是当天零点，所有特征都必须能在此前生成。

## 四类常见泄漏

1. **目标泄漏：** 特征直接或间接包含标签结果。
2. **时间泄漏：** 使用预测时点之后的数据，或随机打乱本应按时间部署的样本。
3. **实体泄漏：** 同一用户、设备、病例或近重复样本跨集合。
4. **预处理泄漏：** 转换器在验证或测试数据上进行了 `fit`。

## 最小手算

训练目标 `[0, 0, 1, 1]`。若加入特征 `x=y`，规则 `x>0.5` 的准确率是 100%。这并不说明模型预测了未来，只说明输入已经写着答案。判断关键不是相关性多强，而是预测时能否获得。

## 可执行实验

```python
import numpy as np
from sklearn.feature_selection import SelectKBest
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import make_pipeline

rng = np.random.default_rng(42)
X = rng.normal(size=(200, 5000))
y = rng.integers(0, 2, size=200)
selector = SelectKBest(k=20)
X_leaked = selector.fit_transform(X, y)
bad = cross_val_score(LogisticRegression(max_iter=1000), X_leaked, y, cv=5)
safe = cross_val_score(
    make_pipeline(SelectKBest(k=20), LogisticRegression(max_iter=1000)),
    X, y, cv=5
)
print("select before CV", round(bad.mean(), 3))
print("select inside CV", round(safe.mean(), 3))
```

标签完全随机，真实能力应接近 0.5。全量选特征先看过所有标签，往往产生虚假高分；Pipeline 在每折内部选择，估计更接近随机。

## 评测与结果解释

异常高分、极少特征决定结果、随机拆分远好于时间拆分，都是调查信号而非泄漏证明。可通过删除可疑列、推迟截断时间、按实体去重和建立时间回放来复验。

## 数据与泄漏风险

为每个字段记录来源系统、事件时间、入库时间、允许的最大延迟和生成 SQL。标签也要定义观察窗口。数据修订会让历史回放看到“当时未知的最终值”，因此需要时间点正确的快照。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| AUC 接近 1 | 目标代理或未来字段 | 单列分数、字段血缘、时间戳 |
| 随机拆分远好于时间拆分 | 时间泄漏或漂移 | 部署时间线、特征截止时间 |
| 交叉验证好线上差 | 实体重叠或预处理泄漏 | 用户交集、Pipeline 边界 |
| 删除 ID 后骤降 | 模型记住实体 | 唯一值率、分组拆分 |

## 适用与不适用场景

任何数据驱动模型都必须做泄漏审计。相关性高不等于泄漏，只要该特征在预测时真实可得；反之，相关性不高的全局预处理也可能造成轻微但真实的泄漏。

## 学习收益

你应能从时间、目标、实体和预处理四个方向审计数据，解释为何 Pipeline 能降低泄漏风险，并设计删除特征与回放实验。

## 给别人讲清楚

“泄漏就像让考生在练习时看到了答案。分数越高不一定越好，先问每条信息在真正答题时是否存在。”
