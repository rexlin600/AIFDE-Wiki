# 校准

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

分类器会排序，不代表概率可信。校准要求：模型对一组样本给出约 0.8 的概率时，其中约 80% 真正发生。预算、风控和期望收益都依赖这种含义。

## 不理解会造成什么错误

- 把任意模型分数直接称为概率。
- 只看 AUC，拿过度自信的概率计算资金风险。
- 在训练模型的同一批样本上拟合校准器。
- 基准率变化后仍沿用旧概率和阈值。

## 它在建模工作流中的位置

模型先学习区分样本，校准器再用独立数据学习“模型分数到真实频率”的映射。阈值决策位于校准之后，并由[指标](06-指标.md)和业务成本决定。

## 从流失概率开始

挽留模型把 100 名客户都预测为 0.8，但实际只有 50 人流失。排序也许仍好，概率却明显过高。若每人优惠成本 30 元、流失损失 100 元，错误概率会直接造成预算误判。

## 核心机制

可靠性图把预测概率分箱，横轴是箱内平均预测，纵轴是实际正类比例；越接近对角线越可靠。Brier Score 为：

$$
\operatorname{Brier}=\frac{1}{n}\sum_i(p_i-y_i)^2
$$

- **Platt Scaling：** 用逻辑函数平滑映射原分数，数据少时较稳。
- **Isotonic：** 学习单调阶梯映射，更灵活但更容易过拟合。
- **交叉验证校准：** 让校准器看到折外预测，避免在模型已经拟合的样本上学习。

Brier 同时受区分能力与校准影响，因此还需可靠性图，不能只看一个分数。

## 最小手算

真实标签 `[1,0]`，概率 `[0.8,0.8]`：

$$
\operatorname{Brier}=((0.8-1)^2+(0.8-0)^2)/2=0.34
$$

若改成 `[0.5,0.5]`，Brier 为 0.25。虽然两个样本无法评价排序，但第二组与这一小组的发生率更一致。

## 可执行实验

```python
from sklearn.calibration import CalibratedClassifierCV
from sklearn.datasets import make_classification
from sklearn.metrics import brier_score_loss, roc_auc_score
from sklearn.model_selection import train_test_split
from sklearn.svm import LinearSVC

X, y = make_classification(
    n_samples=1200, n_features=12, class_sep=0.8, random_state=42
)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, stratify=y, random_state=42
)
model = CalibratedClassifierCV(LinearSVC(random_state=42), method="sigmoid", cv=5)
model.fit(X_train, y_train)
probability = model.predict_proba(X_test)[:, 1]
print("Brier", round(brier_score_loss(y_test, probability), 3))
print("AUC", round(roc_auc_score(y_test, probability), 3))
for low in (0.0, 0.2, 0.4, 0.6, 0.8):
    mask = (probability >= low) & (probability < low + 0.2)
    if mask.any():
        print(round(probability[mask].mean(), 2), round(y_test[mask].mean(), 2), mask.sum())
```

每行依次是箱内平均预测、真实发生率和样本数。小箱的差异可能只是抽样噪声，因此要同时看数量。

## 评测与结果解释

校准前后同时比较 AUC、Brier、Log Loss 和可靠性图。校准可能改善概率却轻微改变排序。训练、校准、阈值选择和最终测试必须隔离；交叉验证校准可更有效地使用数据。

## 数据与泄漏风险

不能在测试集拟合校准器。时间变化任务应在较新的校准窗口拟合，再在更未来窗口测试。过采样改变了训练基准率，输出概率需在原始分布上校准。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| AUC 好而 Brier 差 | 排序好但概率失真 | 可靠性图、过度自信区间 |
| 高概率箱样本很少 | 分箱过细 | 每箱数量、分位数分箱 |
| 上线后概率整体偏低 | 基准率漂移 | 近期正类率、时间校准窗 |
| Isotonic 曲线锯齿 | 校准样本不足 | 改用 sigmoid、增加样本 |

## 适用与不适用场景

当概率用于金额、风险、资源或跨模型比较时必须检查校准。只需要固定容量排序时，排序指标可能更重要，但也不能把分数解释为发生率。

## 学习收益

你应能解释“0.8 概率”的可验证含义，手算 Brier，区分排序与校准，并设计无泄漏的校准数据流程。

## 给别人讲清楚

“排序回答谁更可能发生，校准回答到底有多可能。前者像名次，后者像可信的温度计刻度。”
