# 时间序列

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么机器学习问题

时间序列用过去预测未来，例如预测明日订单量。时间顺序、预测跨度和信息发布时间决定任务，不能把记录随机打乱后当普通回归。

## 不理解会造成什么错误

- 随机拆分，让模型用未来季节和趋势预测过去。
- 滚动均值包含当天目标，产生一行代码的泄漏。
- 与全局均值比较，却不与“昨天”或“上周同日”比较。
- 单步训练后递归预测很远，却不评估误差累积。

## 它在建模工作流中的位置

先定义预测起点、提前量、预测跨度和数据可用延迟，再构造滞后特征并做滚动回测。模型复杂度在可靠季节性基线之后考虑。

## 从需求预测开始

每天凌晨预测未来 7 天各门店订单量，用于排班。样本是“门店 × 日期”，标签是未来某日需求，特征仅含凌晨前已发布的数据。低估导致缺人，高估导致闲置成本。

## 先建立简单基线

- **最后值：** 明天等于今天。
- **季节性朴素：** 本周一等于上周一，$\hat y_t=y_{t-7}$。
- **移动平均：** 用最近若干个已完成时点平均。

强模型若不能稳定超过季节性朴素预测，通常不值得增加维护成本。

## 核心机制

滞后回归把过去值作为输入：

$$
\hat y_t=w_0+w_1y_{t-1}+w_2y_{t-7}+w_3\bar y_{t-7:t-1}
$$

趋势是长期水平变化，季节性是固定周期模式，残差是两者未解释的变化。直接多步模型分别预测每个跨度；递归模型把前一步预测作为下一步输入，可能累积误差。

## 最小手算

过去两周一销量分别为 100 和 120。预测下周一时，季节性朴素给 120；两周同日均值给 110。真实值若为 125，两者绝对误差分别为 5 和 15。

## 可执行实验

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

rng = np.random.default_rng(42)
t = np.arange(180)
y = 50 + 0.08 * t + 8 * np.sin(2 * np.pi * t / 7) + rng.normal(0, 2, len(t))
X = np.column_stack([np.roll(y, 1), np.roll(y, 7)])
valid = np.arange(7, len(y))
train = valid[valid < 140]
test = valid[valid >= 140]
model = LinearRegression().fit(X[train], y[train])
model_prediction = model.predict(X[test])
seasonal_prediction = y[test - 7]
print("seasonal MAE", round(mean_absolute_error(y[test], seasonal_prediction), 3))
print("lag model MAE", round(mean_absolute_error(y[test], model_prediction), 3))
```

训练索引严格早于测试索引。真实项目应在多个预测起点重复回测，而不是只切一次。

## 评测与结果解释

按每个预测跨度分别报告 MAE 或业务损失，并比较季节性基线。用多个滚动窗口观察稳定性；节假日、大促和缺货时段单独切片。缺货导致的销量不是完整需求，标签含义必须澄清。

## 数据与泄漏风险

所有 rolling 特征先 `shift` 再聚合。天气预报应使用当时发布的预报版本，不能使用事后观测天气。随机交叉验证、中心化窗口和全量季节均值都会偷看未来。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 随机验证极好回测差 | 未来信息泄漏 | 拆分顺序、rolling 与 shift |
| 周末误差持续偏高 | 季节性未建模 | 周期滞后、日历特征、分日残差 |
| 长跨度迅速变差 | 递归误差累积 | 分跨度指标、直接多步模型 |
| 大促总低估 | 训练中事件少或特征晚到 | 活动计划、可用时间、场景兜底 |

## 适用与不适用场景

只要未来顺序不可交换，就应使用时序验证。若目标主要由静态实体差异决定，也可用表格模型，但拆分仍必须尊重时间。结构突变时，复杂历史模型未必优于近期基线。

## 学习收益

你应能定义预测起点与跨度，建立季节性朴素基线，构造无泄漏滞后特征，并设计滚动回测与分跨度报告。

## 给别人讲清楚

“时序预测的核心不是把日期塞进模型，而是在每个历史时点只使用当时已经知道的信息，反复模拟向前预测。”
