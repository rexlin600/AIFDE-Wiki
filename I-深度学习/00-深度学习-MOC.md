# 深度学习 MOC

<!-- markdownlint-disable MD012 MD013 -->

## 为什么学习深度学习

深度学习让模型从数据中逐层学习表示，特别适合图像、语音、文本、图和大规模生成任务。真正需要掌握的不是架构名称，而是一条能够被观察和排错的训练链：张量怎样流动、损失怎样产生、梯度怎样返回、参数怎样更新，以及模型怎样验证、保存和推理。

## 领域边界

本目录讲神经网络训练机制、经典架构和 PyTorch 工程。数学原理来自 [AI 基础](../G-AI%20%E5%9F%BA%E7%A1%80/00-AI%20%E5%9F%BA%E7%A1%80-MOC.md)，数据拆分、指标和泄漏来自[机器学习](../H-%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0/00-%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0-MOC.md)。Transformer 在这里讲结构与训练；预训练、对齐和生成应用进入[大模型 LLM](../J-%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM/00-%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM-MOC.md)。

## 按训练系统学习

1. **建立前向：** [多层感知机 MLP](<01-多层感知机 MLP.md>)解释层、激活与张量形状。
2. **计算梯度：** [神经网络反向传播](02-神经网络反向传播.md)把损失分配到每个参数。
3. **让信号稳定：** [神经网络参数初始化](03-神经网络参数初始化.md)控制激活与梯度尺度。
4. **更新参数：** [神经网络优化器](04-神经网络优化器.md)决定沿梯度怎样走。
5. **控制泛化：** [神经网络正则化](05-神经网络正则化.md)抑制对训练样本的记忆。
6. **写出系统：** [PyTorch 模型训练](<10-PyTorch 模型训练.md>)贯通数据、训练、验证和推理。
7. **定位故障：** [深度学习训练诊断](11-深度学习训练诊断.md)检查损失、梯度与激活。
8. **保存交付：** [批处理与模型序列化](12-批处理与模型序列化.md)处理变长输入和检查点恢复。
9. **扩大规模：** [混合精度与分布式训练](13-混合精度与分布式训练.md)控制精度、内存与通信。
10. **优化执行：** [自定义算子与模型编译](16-自定义算子与模型编译.md)在正确基线之后处理性能瓶颈。

| 现象 | 优先入口 | 首要问题 |
| --- | --- | --- |
| 损失完全不下降 | [深度学习训练诊断](11-深度学习训练诊断.md) | 一个小批次能否过拟合，参数是否真的更新 |
| 梯度消失或爆炸 | [神经网络参数初始化](03-神经网络参数初始化.md) | 激活、梯度范数和层间方差怎样变化 |
| 更新震荡或很慢 | [神经网络优化器](04-神经网络优化器.md) | 学习率、动量和批量是否匹配 |
| 训练好而验证差 | [神经网络正则化](05-神经网络正则化.md) | 数据泄漏、容量、增强和早停 |
| 变长序列结果错误 | [批处理与模型序列化](12-批处理与模型序列化.md) | Padding 是否被 Mask，长度轴是否正确 |
| 出现 NaN 或 Inf | [混合精度与分布式训练](13-混合精度与分布式训练.md) | 首个非有限值、损失尺度和不稳定算子 |

| 推理变慢或反复编译 | [自定义算子与模型编译](16-自定义算子与模型编译.md) | 瓶颈、动态图中断和形状变化在哪里 |

## 统一形状约定

- $B$ 表示批大小，$T$ 表示序列长度，$D$ 表示隐藏维度，$K$ 表示类别数。
- 图像使用 `[B,C,H,W]`，其中 $C$ 是通道数；序列使用 `[B,T,D]`。
- 每次改变形状都应写出每个轴的含义；能运行不代表语义正确。

## 推荐学习路线

- **第一次入门：** MLP → 反向传播 → 初始化 → 优化器 → 正则化 → PyTorch 模型训练 → 训练诊断。
- **视觉任务：** 训练基础 → CNN → 批处理与序列化 → 混合精度与分布式训练。
- **序列与 Transformer：** RNN/LSTM → Attention → Transformer → 批处理与序列化。
- **扩展研究：** 生成模型或图神经网络 → 自定义算子与模型编译。

## 上线检查表

| 阶段 | 必须能回答的问题 |
| --- | --- |
| 数据 | 样本、标签、拆分和预测时点是否正确 |
| 形状 | 每个轴表示什么，Mask 能否广播到正确位置 |
| 训练 | 损失是否匹配输出，梯度是否存在且尺度合理 |
| 验证 | 是否切换 `eval`，是否关闭梯度，指标是否匹配任务 |
| 恢复 | 检查点能否从中断处继续并复现固定输入输出 |
| 性能 | 瓶颈在数据、计算、内存还是通信，优化是否有基线 |

## 实践项目

用合成数据完成一个小型分类系统：先让模型过拟合一个小批次，再加入独立验证，保存并恢复检查点，核对固定输入输出，最后记录损失、梯度范数、每步时间和失败案例。只有表格强基线不足且数据形态适合时，才升级到更复杂架构。
