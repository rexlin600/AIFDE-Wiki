# 图神经网络

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么深度学习问题

有些数据的关键不只在每个对象自身，还在对象之间的关系。交易账户、分子原子、商品与用户都能表示为图。图神经网络通过邻居传递信息，完成节点分类、边预测或整张图分类。

## 不理解会造成什么错误

- 把邻接矩阵方向写反，让消息从错误方向传播。
- 未加自环，更新后丢失节点自己的信息。
- 在拆分训练边后仍保留能直接暴露测试标签的关系。
- 堆很多层造成过度平滑，所有节点表示越来越相似。

## 它在训练系统中的位置

GNN 仍由线性层、激活、损失和反向传播组成，特殊之处是每层先按图结构聚合邻居。它继承[神经网络参数初始化](03-神经网络参数初始化.md)和[神经网络正则化](05-神经网络正则化.md)的训练方法，但验证必须额外考虑关系泄漏。

## 从关系欺诈检测开始

节点是账户，边表示设备共享或资金转移，节点特征是预测时点前的行为统计，标签是未来确认的欺诈。输入节点矩阵为 `[N,D]`，邻接矩阵为 `[N,N]`，输出为 `[N,C]`。基线只用节点自身特征做 MLP；GNN 必须证明关系信息带来稳定增益。

## 消息传递直觉

一层消息传递包含三步：

1. 从每个邻居产生消息；
2. 用求和、均值或最大值聚合，保证不依赖邻居排列顺序；
3. 将聚合结果与节点自身表示组合并变换。

通用写法是：

$$
m_v^{(l)}=\operatorname{AGG}\{M(h_v^{(l)},h_u^{(l)},e_{uv}):u\in\mathcal N(v)\}
$$

$$
h_v^{(l+1)}=U(h_v^{(l)},m_v^{(l)})
$$

## 从邻居平均推到 GCN

给邻接矩阵 $A$ 加自环：$\tilde A=A+I$。令 $\tilde D_{ii}=\sum_j\tilde A_{ij}$。对称归一化后的传播矩阵是：

$$
\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}
$$

一层 GCN 为：

$$
H^{(l+1)}=\sigma(\hat A H^{(l)}W^{(l)})
$$

形状依次为 `[N,N] @ [N,D] @ [D,H] → [N,H]`。归一化避免高度数节点的消息仅因邻居多而无限放大。

## 最小手算

三个节点组成链 `0—1—2`，标量特征为 `[1,2,5]`。若加自环后做简单邻居均值：

- 节点 0 聚合自己和节点 1，得到 $(1+2)/2=1.5$；
- 节点 1 聚合三个节点，得到 $(1+2+5)/3=8/3$；
- 节点 2 聚合节点 1 和自己，得到 $(2+5)/2=3.5$。

这说明一层后每个节点获得一跳邻域信息，两层可传播到两跳。

## NumPy 消息聚合

```python
import numpy as np

A = np.array([[0, 1, 0], [1, 0, 1], [0, 1, 0]], dtype=float)
X = np.array([[1.0], [2.0], [5.0]])
A_self = A + np.eye(3)
D_inv_sqrt = np.diag(1 / np.sqrt(A_self.sum(axis=1)))
A_hat = D_inv_sqrt @ A_self @ D_inv_sqrt
H = A_hat @ X
print("normalized adjacency\n", np.round(A_hat, 3))
print("new node states", np.round(H.ravel(), 3))
assert H.shape == (3, 1)
```

对称归一化不是简单算术平均，所以输出与上一节的直觉手算略有不同；两者都满足邻居排列不影响聚合结果。

## PyTorch 节点分类实验

```python
import torch

torch.manual_seed(42)
A = torch.tensor([
    [0, 1, 0, 0], [1, 0, 1, 0],
    [0, 1, 0, 1], [0, 0, 1, 0],
], dtype=torch.float32)
X = torch.tensor([[1., 0.], [1., 1.], [0., 1.], [0., 2.]])
labels = torch.tensor([0, 0, 1, 1])
A = A + torch.eye(4)
degree = A.sum(dim=1)
A_hat = degree.rsqrt()[:, None] * A * degree.rsqrt()[None, :]
layer1 = torch.nn.Linear(2, 4, bias=False)
layer2 = torch.nn.Linear(4, 2, bias=False)
optimizer = torch.optim.Adam([*layer1.parameters(), *layer2.parameters()], lr=0.05)
for _ in range(100):
    optimizer.zero_grad(set_to_none=True)
    hidden = torch.relu(A_hat @ layer1(X))
    logits = A_hat @ layer2(hidden)
    loss = torch.nn.functional.cross_entropy(logits, labels)
    loss.backward()
    optimizer.step()
print("shape", tuple(logits.shape), "prediction", logits.argmax(1).tolist())
```

示例在整张小图上训练，只展示消息传递。真实节点分类必须声明哪些节点标签用于训练，以及模型在训练时能看到哪些边和无标签节点特征。

## 实验结果解释

比较 MLP 基线与 GNN 时保持节点特征、拆分和指标一致。增益可能来自真实关系，也可能来自标签同质性、实体重复或未来边。需要做删边、打乱边和只用自身特征的消融。

## 训练与推理差异

训练时可能对邻居采样以控制内存，推理时可全图计算或逐批采样。新节点到达时，其邻居特征和边必须同步可用。全图转导设置允许训练时看见测试节点的无标签特征；归纳设置则要求泛化到全新节点或图，两者不可混报。

## 数据与验证风险

关系具有时间。用未来建立的转账边、设备共享或引用关系预测过去会泄漏。随机拆节点可能让同一实体群跨集合，应按时间、连通群或真实部署实体设计[验证](../H-%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0/11-%E9%AA%8C%E8%AF%81%E8%AE%BE%E8%AE%A1.md)。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| GNN 不如 MLP | 边无信息或聚合错误 | MLP 基线、删边消融、邻接方向 |
| 多层后节点表示相同 | 过度平滑 | 层数、表示余弦相似度、残差 |
| 显存随边数爆炸 | 全图稠密邻接或高阶邻居 | 稀疏表示、邻居采样、度分布 |
| 离线分数异常高 | 未来边或实体群泄漏 | 边时间、连通分量、标签传播 |
| 新节点无法预测 | 缺少邻居或转导假设 | 冷启动基线、归纳特征、边延迟 |

## 适用与不适用场景

当关系对目标有增量信息且预测时可得时，GNN 值得比较。若边只是随机连接、关系过时或节点自身特征已经足够，MLP 更简单。图规模巨大时还要证明采样和服务成本可接受。

## 学习收益

你应能标注图张量形状，手算邻居聚合，推导 GCN 归一化，区分转导与归纳设置，并通过边消融和时间审计判断关系是否真实有用。

## 给别人讲清楚

“普通网络只看一个对象自己的资料，图网络还让它听取邻居的信息；听谁、怎样汇总以及这些关系在预测时是否存在，决定了结果是否可信。”
