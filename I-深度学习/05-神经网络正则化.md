# 神经网络正则化

<!-- markdownlint-disable MD013 -->

## 它解决什么深度学习问题

参数很多的网络可以记住小型训练集，训练损失接近零，遇到新样本却失败。正则化通过限制参数、扰动训练样本或控制训练时机，让模型优先学习可重复的规律，而不是偶然噪声。

## 不理解会造成什么错误

- 把训练损失升高当成正则化失败，忽略验证表现。
- 推理时仍启用 Dropout，导致同一输入输出随机变化。
- 在拆分数据之前增强，造成原图与变体跨集合泄漏。
- 用更强正则化掩盖错误标签、分布偏移或数据泄漏。

## 它在训练系统中的位置

正则化贯穿多个环节：Weight Decay 修改参数更新，Dropout 修改训练前向，数据增强修改训练输入，早停根据验证曲线决定何时结束。它们共同目标是缩小训练与验证差距，但机制不同。

## 从小数据图像分类开始

假设只有 80 张缺陷图像。大型 MLP 很快记住训练图，验证准确率却在若干轮后下降。错误成本以漏检为主，因此不仅要保存最高验证准确率，还应按验证召回率或业务代价选择检查点。

## 先建立简单基线

先固定按设备或产品批次划分的训练、验证、测试集，训练一个容量较小且不加正则化的模型。画出训练和验证损失：只有确认出现过拟合，才能判断正则化是否解决了目标问题。

## 四种常见机制

| 方法 | 改变什么 | 主要作用 |
| --- | --- | --- |
| Weight Decay | 每步缩小参数 | 限制权重尺度 |
| Dropout | 随机屏蔽隐藏单元 | 减少特征之间的脆弱共适应 |
| 数据增强 | 生成保持标签的训练变体 | 注入任务不变性并扩大覆盖 |
| 早停 | 保存验证最优轮次 | 避免继续拟合训练噪声 |

## Weight Decay 与 L2 推导

在线性 SGD 中，把 L2 惩罚加入目标：

$$
J(\theta)=L(\theta)+\frac\lambda2\lVert\theta\rVert_2^2
$$

因为 $\nabla_\theta\frac12\lVert\theta\rVert^2=\theta$，更新为：

$$
\theta_{t+1}=\theta_t-\eta(\nabla L+\lambda\theta_t)
=(1-\eta\lambda)\theta_t-\eta\nabla L
$$

因此普通 SGD 下 L2 与权重衰减等价。对 Adam 等自适应优化器，若把 L2 梯度一起缩放便不再等价，AdamW 才把衰减解耦。

## Dropout 的期望为何保持不变

对激活 $h$，训练时采样 $m\sim\operatorname{Bernoulli}(q)$，$q$ 是保留概率。倒置 Dropout 输出：

$$
\tilde h=\frac{m}{q}h
$$

其期望为：

$$
\mathbb E[\tilde h]
=\frac{\mathbb E[m]}{q}h
=\frac q qh=h
$$

所以训练时已完成尺度补偿，推理时不需再乘 $q$。但训练输出仍有随机方差，推理模式则使用完整激活。

## 最小手算

设激活 $h=[2,4]$，保留概率 $q=0.5$：

- 掩码 `[1,0]` 时，输出为 `[4,0]`；
- 掩码 `[0,1]` 时，输出为 `[0,8]`；
- 掩码 `[0,0]` 时，输出为 `[0,0]`；
- 掩码 `[1,1]` 时，输出为 `[4,8]`；
- 四种等可能输出的平均是 `[2,4]`，等于原激活。

这只说明期望保持，不表示单次训练输出等于推理输出。

## NumPy 复刻 Dropout

```python
import numpy as np

rng = np.random.default_rng(29)
x = np.array([2.0, 4.0, 6.0])
keep_prob = 0.7
samples = []
for _ in range(50_000):
    mask = rng.binomial(1, keep_prob, size=x.shape)
    samples.append(mask * x / keep_prob)
mean_output = np.mean(samples, axis=0)
assert np.allclose(mean_output, x, atol=0.04)
print("input:", x, "mean dropout output:", mean_output.round(3))
```

## PyTorch 逐项对照实验

下面在同一数据、初始化和训练预算下分别开启 Weight Decay、Dropout 与数据增强，并额外比较组合方案和早停。单个随机种子的对照用于理解机制，不足以证明某一项稳定提升。

```python
import torch
from torch import nn

torch.manual_seed(29)
train_x = torch.linspace(-2, 2, 40).unsqueeze(1)
train_y = (train_x[:, 0] > 0).long()
train_y[::7] = 1 - train_y[::7]  # 模拟少量训练标签噪声
valid_x = torch.linspace(-1.95, 1.95, 80).unsqueeze(1)
valid_y = (valid_x[:, 0] > 0).long()

def run(dropout=0.0, weight_decay=0.0, augment=False, early_stop=False):
    torch.manual_seed(29)
    model = nn.Sequential(nn.Linear(1, 32), nn.ReLU(), nn.Dropout(dropout), nn.Linear(32, 2))
    optimizer = torch.optim.AdamW(
        model.parameters(), lr=0.03, weight_decay=weight_decay
    )
    best_accuracy = 0.0
    best_state = None
    stale = 0
    final_accuracy = 0.0
    epochs = 0
    for epoch in range(250):
        model.train()
        features = train_x + 0.03 * torch.randn_like(train_x) if augment else train_x
        optimizer.zero_grad()
        loss = nn.functional.cross_entropy(model(features), train_y)
        loss.backward()
        optimizer.step()
        model.eval()
        with torch.inference_mode():
            accuracy = (model(valid_x).argmax(1) == valid_y).float().mean().item()
        final_accuracy = accuracy
        epochs = epoch + 1
        if accuracy > best_accuracy:
            best_accuracy = accuracy
            best_state = {key: value.detach().clone() for key, value in model.state_dict().items()}
            stale = 0
        else:
            stale += 1
        if early_stop and stale >= 30:
            break
    if early_stop:
        model.load_state_dict(best_state)
        final_accuracy = best_accuracy
    return model, final_accuracy, epochs

configs = {
    "plain": {},
    "weight_decay": {"weight_decay": 0.03},
    "dropout": {"dropout": 0.25},
    "augmentation": {"augment": True},
    "combined": {"dropout": 0.25, "weight_decay": 0.03, "augment": True},
    "combined_early_stop": {
        "dropout": 0.25, "weight_decay": 0.03,
        "augment": True, "early_stop": True,
    },
}
results = {name: run(**options) for name, options in configs.items()}
regularized, regularized_acc, _ = results["combined_early_stop"]
regularized.eval()
with torch.inference_mode():
    output_a = regularized(valid_x)
    output_b = regularized(valid_x)
assert torch.equal(output_a, output_b)
assert all(result[1] >= 0.85 for result in results.values())
for name, (_, accuracy, epochs) in results.items():
    print(name, "validation", round(accuracy, 3), "epochs", epochs)
```

## 如何解释实验结果

结果表让每个开关相对同一 plain 基线可见，并展示早停如何缩短训练和恢复最佳状态。单次小实验不保证正则化一定胜出，尤其当基线尚未过拟合时；正式结论需要多随机种子报告均值和方差。

## 训练与推理差异

Dropout 在 `model.train()` 时随机屏蔽单元，在 `model.eval()` 时关闭。验证和推理还应用 `torch.inference_mode()` 避免构图。数据增强通常只用于训练；推理若使用测试时增强，必须明确聚合规则和额外延迟。

早停保存的是验证最优状态，而非循环结束时的最后状态。继续训练需要同时保存优化器与步数，仅恢复模型参数不足以精确续训。

## 数据与验证风险

- 必须先拆分，再只对训练集增强；同一原始对象的变体不可跨集合。
- 早停反复查看验证集，因此验证集不能再充当最终测试集。
- 增强必须保持标签语义；翻转文字、改变医学图像方向可能改变标签。
- 正则化无法修复未来信息、重复样本和错误的评估指标。

详见[数据泄漏](../H-机器学习/05-数据泄漏.md)和[验证设计](../H-机器学习/11-验证设计.md)。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 验证输出每次不同 | 推理时仍处于训练模式 | 调用 `eval` 并检查 Dropout |
| 训练与验证都很差 | 正则过强或模型欠拟合 | 先关闭正则化验证小批次可拟合 |
| 训练很好验证骤降 | 容量过大、泄漏式调参或分布偏移 | 核对拆分与训练验证曲线 |
| 增强后性能下降 | 增强改变了标签语义 | 可视化增强样本并请领域专家核对 |
| 早停恢复结果不佳 | 保存了最后状态而非最佳状态 | 记录最佳指标对应的 `state_dict` |

## 适用与不适用场景

Weight Decay 是常用的参数约束；Dropout 适合全连接层和部分序列模型，但并非所有现代架构都需要；数据增强在已知标签不变性时最有价值；早停适合验证指标能代表部署目标的任务。数据不足时，迁移学习或收集高质量样本通常比盲目加大正则更重要。

## 学习收益

读完后应能区分四类正则化作用位置，推导倒置 Dropout 的期望和 SGD 下的权重衰减，正确切换训练验证模式，并设计无泄漏消融。

## 给别人讲清楚

正则化不是单一开关，而是一组“减少死记硬背”的约束：限制参数幅度、随机拿走部分线索、提供合理变体，或在模型开始记噪声前停止。好坏看验证表现，不看训练损失是否最低。
