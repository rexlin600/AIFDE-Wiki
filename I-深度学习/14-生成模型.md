# 生成模型

<!-- markdownlint-disable MD012 MD013 -->

## 它解决什么深度学习问题

判别模型学习“输入属于什么类别”，生成模型学习数据怎样产生，从而能够压缩、重建、补全或采样新数据。图像生成、语音合成、异常重建和数据增强都建立在不同形式的生成建模上。

## 不理解会造成什么错误

- 把自编码器、GAN 和扩散模型理解成同一个算法的不同名字。
- 只看少量好样本，忽略模式坍塌、记忆训练数据和采样偏差。
- 把像素重建误差低等同于语义质量高。
- 用训练数据和测试数据共同选择生成样本或评测器。

## 它在训练系统中的位置

生成模型仍使用前向、损失、[神经网络反向传播](02-神经网络反向传播.md)和[神经网络优化器](04-神经网络优化器.md)，区别在于学习目标和采样过程。它是理解后续大型生成模型的桥梁，但本篇不展开 LLM 训练与对齐。

## 从二维数据生成开始

假设真实数据是平面上的两个点云。输入形状为 `[B,2]`，目标不是给每个点分类，而是学会产生分布相似的新点。基线可以从训练点中随机重采样；复杂模型必须在覆盖度、新颖性和保真度上说明改进。

## 三条主要路线

### 自编码器

编码器把 $x$ 压成 $z=f_\theta(x)$，解码器重建 $\hat x=g_\phi(z)$，常最小化：

$$
L_{AE}=\frac{1}{B}\sum_i\lVert x_i-g_\phi(f_\theta(x_i))\rVert_2^2
$$

普通自编码器没有规定潜空间中的哪些 $z$ 可以采样，所以“能重建”不自动等于“会生成”。变分自编码器为 $z$ 引入概率分布和先验约束。

### 生成对抗网络

生成器 $G(z)$ 产生样本，判别器 $D(x)$ 区分真假。经典目标是：

$$
\min_G\max_D\ E_{x\sim p_{data}}\log D(x)
+E_{z\sim p(z)}\log(1-D(G(z)))
$$

两方博弈可产生锐利样本，但训练可能不稳定，生成器可能只覆盖少数模式。

### 扩散模型

前向过程逐步给数据加高斯噪声：

$$
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,
\quad\epsilon\sim\mathcal N(0,I)
$$

网络接收 $x_t$ 与时间 $t$，学习预测噪声 $\epsilon$。训练常用：

$$
L_{simple}=E\lVert\epsilon-\epsilon_\theta(x_t,t)\rVert_2^2
$$

采样从噪声出发，反复预测并去除噪声。它通常稳定但需要多步采样。

## 扩散闭式加噪怎样得到

若单步为 $x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{1-\alpha_t}\epsilon_t$，连续代入两步后，$x_0$ 的系数变为 $\sqrt{\alpha_t\alpha_{t-1}}$。独立高斯噪声的方差相加，噪声总方差为 $1-\alpha_t\alpha_{t-1}$。推广到 $t$ 步并记 $\bar\alpha_t=\prod_{s=1}^t\alpha_s$，就得到上面的闭式表达。

## 最小手算

一维数据 $x_0=2$，设 $\bar\alpha_t=0.81$、采样噪声 $\epsilon=-1$：

$$
x_t=0.9\times2+\sqrt{0.19}\times(-1)\approx1.364
$$

模型要从带时间标记的 1.364 估计这次加入的噪声，而不是直接背诵原始样本。

## NumPy 加噪实验

```python
import numpy as np

rng = np.random.default_rng(42)
x0 = rng.normal(loc=[2.0, -1.0], scale=0.5, size=(1000, 2))
epsilon = rng.normal(size=x0.shape)
for alpha_bar in (0.9, 0.5, 0.1):
    xt = np.sqrt(alpha_bar) * x0 + np.sqrt(1 - alpha_bar) * epsilon
    correlation = np.corrcoef(x0[:, 0], xt[:, 0])[0, 1]
    print(alpha_bar, "mean", np.round(xt.mean(axis=0), 2),
          "correlation", round(correlation, 3))
```

随着 $\bar\alpha_t$ 变小，原数据系数降低，带噪样本与原样本的相关性下降。

## PyTorch 自编码器实验

```python
import torch

torch.manual_seed(42)
x = torch.cat([
    torch.randn(128, 2) * 0.3 + torch.tensor([2.0, 0.0]),
    torch.randn(128, 2) * 0.3 + torch.tensor([-2.0, 0.0]),
])
model = torch.nn.Sequential(
    torch.nn.Linear(2, 4), torch.nn.ReLU(),
    torch.nn.Linear(4, 1),
    torch.nn.Linear(1, 4), torch.nn.ReLU(),
    torch.nn.Linear(4, 2),
)
optimizer = torch.optim.Adam(model.parameters(), lr=0.02)
initial = torch.nn.functional.mse_loss(model(x), x).item()
for _ in range(200):
    optimizer.zero_grad(set_to_none=True)
    loss = torch.nn.functional.mse_loss(model(x), x)
    loss.backward()
    optimizer.step()
final = torch.nn.functional.mse_loss(model(x), x).item()
print("reconstruction", round(initial, 3), "->", round(final, 3))
```

损失下降证明模型学会压缩和重建这组数据，不证明从任意随机潜变量采样都能得到合理样本。

## 实验结果解释

生成质量至少包含保真度与覆盖度：样本像不像真的，以及是否覆盖真实分布的不同模式。还要检查最近训练样本、分群覆盖、条件一致性和人工盲评。单一自动指标可能依赖另一个模型并带有自身偏差。

## 训练与推理差异

自编码器推理可一次前向重建；GAN 只保留生成器采样；扩散训练可随机选择时间步并行加噪，推理却要沿多个时间步顺序去噪。`eval` 模式、条件输入和随机种子都会影响复现。

## 数据与验证风险

生成模型可能记忆训练样本或敏感信息。训练、验证、测试仍需按实体去重并隔离。数据许可、人物肖像和有害内容不能靠损失函数自动解决，部署前需要独立的安全评测。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 自编码器只输出均值 | 瓶颈太小或平方损失平均化 | 潜维度、样本重建、其他似然 |
| GAN 样本高度相似 | 模式坍塌 | 潜变量覆盖、判别器平衡、多样性 |
| 扩散训练损失不降 | 时间编码或噪声目标错误 | $t$、噪声标签、alpha 日程、形状 |
| 样本好看但复制训练集 | 记忆 | 最近邻、去重、成员推断 |
| 采样太慢 | 去噪步数多 | 采样器、步数质量曲线、批量 |

## 适用与不适用场景

自编码器适合表示压缩和重建；GAN 适合重视锐利度且能承受训练调试的任务；扩散适合高质量生成但采样成本较高。若只是做分类或预测，不应因为生成模型更复杂就优先采用。

## 学习收益

你应能区分重建、对抗和去噪目标，推导扩散闭式加噪，解释训练与采样的差异，并从覆盖度、保真度和记忆风险评价生成结果。

## 给别人讲清楚

“自编码器学会压缩再还原，GAN 让生成器和鉴别者互相较量，扩散模型则练习从不同噪声程度中找回信号。它们都能生成，但学习路径不同。”
