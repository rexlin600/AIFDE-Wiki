# 神经网络参数初始化

<!-- markdownlint-disable MD013 -->

## 它解决什么深度学习问题

训练开始时还没有学到参数，初始值却决定信号和梯度能否穿过许多层。值太小，激活与梯度逐层趋近于零；值太大，它们可能爆炸、饱和或产生 NaN。合理初始化让各层在训练开始时处于“既能区分输入，又能收到梯度”的尺度。

## 不理解会造成什么错误

- 所有权重初始化为零，使同层神经元始终学习相同特征。
- 不考虑输入宽度，用固定大方差初始化所有网络。
- ReLU 网络机械套用 Xavier，忽略一半信号被截断。
- 只看初始损失，不检查深层激活与梯度的方差变化。

## 它在训练系统中的位置

初始化发生在第一次前向计算之前，为优化器提供起点。它不改变网络结构和目标，却影响前向信号、反向梯度以及优化器早期看到的尺度。

```text
建模与层宽 → 参数初始化 → 前向与反向 → 优化器更新
```

## 从深层图像分类开始

设一个 20 层网络处理标准化后的图像特征。如果各层权重方差相同但未随输入数调整，越深的层可能只看到几乎全零或极大的数。此时换优化器常常治标不治本，应先记录每层激活均值、标准差和梯度范数。

## 先建立简单基线

浅层网络可先使用框架默认初始化，并固定种子记录结果。增加深度或更换激活后，再根据方差传播选择 Xavier 或 Kaiming，而不是把初始化当成无条件调参项。

## 张量形状与数据流

线性层 $Y=XW$ 中，$X$ 为 `[B,D_in]`，$W$ 为 `[D_in,D_out]`，$Y$ 为 `[B,D_out]`。对一个输出神经元：

$$
y_j=\sum_{i=1}^{D_{in}}x_iw_{ij}
$$

不同输入项近似独立、均值为零时，方差满足：

$$
\operatorname{Var}(y_j)
=D_{in}\operatorname{Var}(x_i)\operatorname{Var}(w_{ij})
$$

## Xavier 初始化的推导

要让前向方差不变，需令 $D_{in}\operatorname{Var}(w)\approx1$。反向传播同理希望 $D_{out}\operatorname{Var}(w)\approx1$。两个条件宽度不等时无法同时严格满足，Xavier 取折中：

$$
\operatorname{Var}(w)=\frac{2}{D_{in}+D_{out}}
$$

若从均匀分布 $U(-a,a)$ 采样，其方差是 $a^2/3$，所以：

$$
a=\sqrt{\frac{6}{D_{in}+D_{out}}}
$$

它适合 Tanh 等近似对称激活。

## Kaiming 初始化的推导

ReLU 把近似对称输入的一半置零，二阶矩大约减半。为了补回这部分信号，需要：

$$
\frac12D_{in}\operatorname{Var}(w)\approx1
\quad\Rightarrow\quad
\operatorname{Var}(w)\approx\frac{2}{D_{in}}
$$

因此正态 Kaiming 初始化的标准差为 $\sqrt{2/D_{in}}$。推导依赖独立、零均值等近似，真实网络还受残差、归一化和数据分布影响。

## 最小手算

若一层有 $D_{in}=100$ 个独立输入，输入方差为 1：

- 权重方差为 1 时，线性输出方差约为 100，逐层快速放大；
- 权重方差为 $1/100$ 时，线性输出方差约为 1；
- 接 ReLU 后二阶矩约剩 0.5，Kaiming 使用 $2/100$ 将二阶矩补回约 1。

这里保持的是二阶矩 $E[x^2]$，不是中心方差。ReLU 输出均值不再为零；对标准高斯输入，其中心方差约为 $(1/2-1/(2\pi))\approx0.341$，小于二阶矩 0.5。

所有权重为零时，每个隐藏单元输出相同、梯度也相同，这种“对称性”不会被训练自行打破。

## NumPy 方差传播实验

```python
import numpy as np

rng = np.random.default_rng(17)
batch, width, depth = 4096, 128, 12
x0 = rng.standard_normal((batch, width))

def propagate(scale):
    x = x0.copy()
    variances = []
    second_moments = []
    local_rng = np.random.default_rng(17)
    for _ in range(depth):
        w = local_rng.standard_normal((width, width)) * scale
        x = np.maximum(0.0, x @ w)
        variances.append(float(x.var()))
        second_moments.append(float(np.mean(x ** 2)))
    return np.array(variances), np.array(second_moments)

small_var, small_m2 = propagate(0.01)
kaiming_var, kaiming_m2 = propagate(np.sqrt(2.0 / width))
large_var, large_m2 = propagate(0.5)
assert small_m2[-1] < 1e-12
assert 0.1 < kaiming_m2[-1] < 5.0
assert large_m2[-1] > 1e6
print("Kaiming final second moment/variance:",
      kaiming_m2[-1], kaiming_var[-1])
```

## PyTorch 激活与梯度实验

```python
import torch
from torch import nn

torch.manual_seed(17)
width, depth = 64, 8

def measure(kind):
    layers = []
    for _ in range(depth):
        layer = nn.Linear(width, width, bias=False)
        if kind == "small":
            nn.init.normal_(layer.weight, std=0.01)
        else:
            nn.init.kaiming_normal_(layer.weight, nonlinearity="relu")
        layers.extend([layer, nn.ReLU()])
    model = nn.Sequential(*layers)
    x = torch.randn(256, width, requires_grad=True)
    output = model(x)
    output.square().mean().backward()
    return output.var().item(), x.grad.var().item()

small_act, small_grad = measure("small")
kaiming_act, kaiming_grad = measure("kaiming")
assert small_act < 1e-12 and small_grad < 1e-12
assert kaiming_act > small_act and kaiming_grad > small_grad
print("small:", small_act, small_grad, "kaiming:", kaiming_act, kaiming_grad)
```

## 如何解释实验结果

错误的小尺度让信号消失，大尺度让信号爆炸，Kaiming 在这组 ReLU 假设下保持可用尺度。单次随机实验不能证明某种初始化对所有模型最好；真正项目还应观察训练损失、逐层统计和多个随机种子。

## 训练与推理差异

初始化只在创建或显式重置模型时发生，推理不应重新初始化。恢复检查点时应先构建兼容结构，再载入已训练的 `state_dict`。如果恢复后又调用初始化函数，会悄悄抹掉训练结果。

## 数据与验证风险

比较初始化方法时，必须保持数据拆分、架构、优化器和训练预算一致，并运行多个种子。只汇报最优种子会高估收益。输入未标准化也会破坏方差推导的前提。

## 工程排错

| 现象 | 可能原因 | 优先检查 |
| --- | --- | --- |
| 深层激活接近零 | 权重太小或激活饱和 | 记录逐层均值与标准差 |
| 激活逐层爆炸 | 初始化方差未按宽度缩放 | 核对 `fan_in` 和初始化模式 |
| 同层单元完全相同 | 权重全零导致对称 | 检查权重直方图 |
| 换激活后训练变差 | 初始化与非线性不匹配 | ReLU 比较 Kaiming，Tanh 比较 Xavier |
| 恢复模型表现随机 | 加载后又被初始化 | 检查构建与 `load_state_dict` 顺序 |

## 适用与不适用场景

Xavier 常用于 Tanh 或近线性激活，Kaiming 常用于 ReLU 族。残差网络、门控网络、极深 Transformer 和特殊激活可能有专用缩放策略；不应只凭名称套公式。预训练模型微调应保留已有权重，只初始化新加的层。

## 学习收益

读完后应能从方差求和推导 Xavier 与 Kaiming 的尺度，解释零初始化的对称性问题，并用激活和梯度统计判断初始化是否健康。

## 给别人讲清楚

初始化像调节每层麦克风增益：层层放大就会爆音，层层缩小就听不见。Xavier 和 Kaiming 根据一层接收多少路信号来调节增益，让信息在深度方向保持合适音量。
