# 阶段 1：AI/ML 基础

## 建议周期与进入条件

**建议周期：6～8 周，每周 5～10 小时。** 时间按实验难度调整，不以看完课程为完成标准。

进入条件是达到阶段 0 的退出标准：能维护 Python 环境、编写测试、暴露 HTTP 服务，并能记录可复现实验。还应能阅读基础统计图表和简单代数表达式。

## 推荐深度与核心知识

核心主题达到 L2，数据泄漏、验证设计和指标选择开始向 L3 推进：

领域入口：[数学与 AI 基础](../C-AI%20%E5%9F%BA%E7%A1%80/00-AI%20%E5%9F%BA%E7%A1%80-MOC.md) → [机器学习](../D-%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0/00-%E6%9C%BA%E5%99%A8%E5%AD%A6%E4%B9%A0-MOC.md) → [深度学习](../E-%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0/00-%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0-MOC.md)。

- 向量、矩阵、导数、梯度、概率分布、期望、方差、熵和交叉熵的工程直觉。
- 监督学习与无监督学习；回归、分类、聚类及一个朴素业务基线。
- 训练/验证/测试拆分、交叉验证、过拟合、正则化、数据泄漏与类别不平衡。
- 精确率、召回率、F1、ROC-AUC、PR-AUC、校准及与业务成本的关系。
- MLP、激活、损失、反向传播、优化器、批处理和初始化。
- PyTorch Tensor、Dataset/DataLoader、Autograd、训练循环、检查点和推理模式。
- 缺失值、重复、标签噪声、分布漂移和错误分析。

## 必做实验

选择一个允许公开使用的表格分类数据集，完成同一问题的三组受控实验：朴素规则或多数类基线、scikit-learn 模型、PyTorch MLP。必须：

1. 在拆分数据前检查重复、时间关系和潜在泄漏字段。
2. 固定训练/验证/测试集合与随机种子，只在验证集上选模型。
3. 比较至少两种指标阈值，并把误报/漏报换算为业务后果。
4. 对 MLP 记录训练/验证损失曲线，执行一次过拟合诊断。
5. 注入一种标签噪声或分布偏移，观察性能和校准变化。

## 外部 GitHub 项目

- [scikit-learn](https://github.com/scikit-learn/scikit-learn)：研究 estimator API、Pipeline 与模型验证实现。
- [PyTorch Examples](https://github.com/pytorch/examples)：复现规范训练循环和保存/加载流程。
- [PyTorch Tutorials](https://github.com/pytorch/tutorials)：对照 Tensor、Autograd、Dataset 与训练最佳实践。

## 开源实践：使用、源码跟踪、最小复刻、可选贡献

- **开源使用：** 使用 scikit-learn Pipeline 与 PyTorch DataLoader 完成相同数据集的训练和评估，固定依赖与随机种子。
- **源码跟踪：** 跟踪一个 scikit-learn estimator 的 `fit/predict` 路径，或 PyTorch 从 `loss.backward()` 到参数更新的关键路径。
- **最小复刻：** 使用 NumPy 独立实现逻辑回归训练，或为两层网络实现前向与反向传播，并用数值梯度检查。
- **可选贡献：** 为文档示例补充边界情况、复现测试或修正文档；先记录 Issue、环境和实际/期望结果。

## 项目增量

创建独立仓库 `ai-foundations-labs`。仓库包括数据卡、探索 Notebook、可运行训练脚本、配置、测试、模型评估报告和实验索引。每个实验写明假设、唯一主要变量、指标、结果与结论，不把 Notebook 输出当作唯一证据。

## 评测与复盘

报告三类模型的验证与测试指标、混淆矩阵、校准、训练/推理时间和资源需求。按数据、目标、拆分、特征、优化和阈值分类失败；解释一个“离线指标提高但业务价值可能下降”的例子。

## 面试训练

- 解释为什么训练集表现好不代表可泛化，以及正则化如何作用。
- 为类别不平衡业务选择指标、阈值和验证方案。
- 白板推导逻辑回归或两层网络的关键梯度，不追求纯公式背诵。
- 排查验证分数异常高、线上表现骤降的问题，并优先检查数据泄漏和分布变化。
- 用项目数据说明为什么最终选择某个基线或模型。

## 退出证据

- `ai-foundations-labs` 的固定版本、环境锁定、自动测试和一键训练/评估命令。
- 三类基线的可重复对比报告，包含数据拆分、指标选择和业务阈值理由。
- 一次数据泄漏检查、一次噪声或漂移实验、一次 PyTorch 过拟合诊断。
- 一份开源调用链记录和经过测试的最小复刻。
- 能从原理、实验、错误分析和业务取舍四层回答面试追问。
