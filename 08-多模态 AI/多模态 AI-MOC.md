# 多模态 AI MOC

## 领域边界

本领域覆盖图像、版式文档、语音与文本之间的理解、生成、检索和交互。重点是把模态模型接入可评测工作流；不深入专用硬件控制，也不把所有非 LLM 算法都归为多模态。

## 前置知识

- [深度学习](../04-%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0/%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0-MOC.md)中的 CNN、Attention、Transformer 与训练评测。
- [LLM](../05-%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM/%E5%A4%A7%E6%A8%A1%E5%9E%8B%20LLM-MOC.md)中的 Token、上下文、结构化输出和模型选型。
- 图像、音频、文档格式以及隐私、版权和无障碍基础。

## 推荐顺序

1. 从 CV、OCR 和文档智能建立视觉与版面基线。
2. 学习 ASR、TTS 与 Voice Agent 的实时音频链路。
3. 使用 VLM 统一文本与视觉任务，再构建多模态检索与评测。
4. 最后了解推荐、预测、机器人、专家系统和进化算法的独立边界。

## 核心主题

| 主题 | 范围 | 建议深度 | 重要程度 |
| --- | --- | --- | --- |
| CV | 分类、检测、分割、预处理、数据偏差和视觉指标 | L2 | core |
| OCR 与文档智能 | 文字识别、版面、表格、阅读顺序、字段抽取和置信度 | L3 | core |
| VLM | 图文输入、视觉 Grounding、结构化理解、幻觉和评测 | L3 | core |
| 多模态检索 | 跨模态 Embedding、索引、召回、Rerank 与引用定位 | L3 | core |

## 常用主题

| 主题 | 范围 | 建议深度 | 重要程度 |
| --- | --- | --- | --- |
| ASR | 分段、转写、说话人、时间戳、噪声与词错误率 | L3 | common |
| TTS | 韵律、音色、流式合成、可懂度、自然度和授权 | L2 | common |
| Voice Agent | VAD、打断、端点检测、ASR/LLM/TTS 串流和延迟预算 | L3 | common |
| 多模态评测 | 模态质量、Grounding、任务成功、延迟、成本与人工复核 | L3 | common |

## 拓展视野

| 主题 | 范围 | 建议深度 | 重要程度 |
| --- | --- | --- | --- |
| 推荐与预测 | 排序、时间序列和业务预测，通常属于专门 ML 系统 | L2 | extension |
| 机器人 | 感知、规划、控制、仿真和物理安全 | L2 | extension |
| 专家系统 | 规则、知识表示、推理与可解释决策 | L2 | extension |
| 进化算法 | 搜索、适应度、变异、组合优化与计算预算 | L2 | extension |

## 最小实验

- 比较 OCR、VLM 与组合流水线对表格和复杂版面文档的字段准确率。
- 构建 ASR → LLM → TTS 的可打断语音链路，分解首响应与端到端延迟。
- 在图文数据上比较文本检索、多模态检索和 Rerank，并检查引用区域。

## 项目

- 为公开文档构建含 OCR、版面解析、多模态检索、引用和人工复核的助手。
- 为公开业务场景构建可打断 Voice Agent，记录准确率、延迟、成本和失败降级。

## 开源研究

- 跟踪一个 OCR/版面模型从预处理到结构化输出的调用链。
- 跟踪一个 ASR 或 TTS 系统的分段、推理和流式输出路径。
- 复刻图文 Embedding 检索最小链路并记录模型与数据许可。

## 面试入口

- 设计复杂 PDF 的解析、检索、引用与人工复核链路。
- 分解 Voice Agent 延迟并处理噪声、打断、误识别和敏感音频。
- 说明何时用专用 CV/OCR/ASR 模型，何时用 VLM。
