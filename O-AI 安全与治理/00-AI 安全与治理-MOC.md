# AI 安全治理 MOC

## 领域边界

本领域覆盖模型、知识库、工具、数据和供应链的 AI 特有攻击面及企业治理要求。目标是在设计、发布、运行和下线全程建立可审计控制；它不替代组织的法律意见或通用信息安全体系。

## 前置知识

- 身份认证、授权、网络隔离、秘密管理、日志审计与威胁建模基础。
- [RAG](../K-%E6%A3%80%E7%B4%A2%E5%A2%9E%E5%BC%BA%E7%94%9F%E6%88%90%20RAG/00-%E6%A3%80%E7%B4%A2%E5%A2%9E%E5%BC%BA%E7%94%9F%E6%88%90%20RAG-MOC.md)的数据权限边界和 [Agent](../L-%E6%99%BA%E8%83%BD%E4%BD%93%20Agent/00-%E6%99%BA%E8%83%BD%E4%BD%93%20Agent-MOC.md)的工具副作用模型。
- [生产 AI](../N-%E7%94%9F%E4%BA%A7%E7%BA%A7%20AI/00-%E7%94%9F%E4%BA%A7%E7%BA%A7%20AI-MOC.md)的评测、Tracing、发布门禁与事件运行机制。

## 推荐顺序

1. 盘点数据、模型、知识库、工具、用户与供应链资产及信任边界。
2. 优先控制 Prompt Injection、数据外泄、过度代理与知识库投毒。
3. 落实认证授权、隔离、审计、PII 和数据驻留。
4. 通过红队、发布门禁与事件响应持续验证控制有效性。

| 数据外泄 | 提示、检索、日志、缓存、模型与工具通道的敏感数据泄露 | L4 | core |

| 审计与事件响应 | 不可抵赖记录、告警、遏制、恢复、取证和复盘 | L3 | core |
| PII 与数据驻留 | 发现、最小化、脱敏、保留、删除、地域与跨境边界 | L4 | core |

## 最小实验

- 对含网页或知识库内容的系统实施直接/间接 Prompt Injection 测试并验证隔离。
- 注入跨租户检索、越权 Tool、PII 日志和供应链版本变化，检查阻断与审计。
- 完成一次红队到告警、遏制、恢复、回归集和无责复盘的桌面演练。

## 项目

- 为公开 RAG 或 Agent 项目交付威胁模型、权限矩阵、安全评测集、审计方案与事件 Runbook。
- 将安全检查接入[阶段 5：生产 AI](../F-%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF/06-%E9%98%B6%E6%AE%B5%205-%E7%94%9F%E4%BA%A7%E7%BA%A7%20AI.md)的 CI/CD 与发布门禁。

## 开源研究

- 跟踪一个授权系统从身份到对象权限判定的调用链。
- 检查所用模型、数据、依赖和容器的来源、许可、锁定版本与漏洞响应。
- 复刻一个只允许白名单操作、强制审批和结构化审计的工具执行层。

## 面试入口

- 威胁建模企业 RAG 的注入、投毒、跨租户泄漏和删除传播。
- 设计高影响 Agent 工具的最小权限、审批、隔离与事故响应。
- 解释红队、持续评测、审计和治理证据如何进入发布流程。
